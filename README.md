请确保以下文件存放在同一个根文件夹中：
* `MAV551_ECA_CAI YUMENG.ipynb` （作业分析过程文件）
* `main.py` （端到端运行脚本）
* `app.py` （交互式网页程序核心代码）
* `xgb_production_pipeline.pkl` （已训练好的端到端模型文件）
* `README.md` （本说明文档）

## 2. 环境安装（仅用于未配置环境的电脑）
在使用前，请确保电脑已安装 Python 及必要的支持库。如缺少库，请打开终端并运行以下命令：

## 3.如何运行模型训练脚本 (main.py)

**💡 提示：** `main.py` 是本项目的核心脚本。如果想**重新训练模型**，或者目录下尚未生成 `xgb_production_pipeline.pkl` 文件，请按照以下步骤运行此脚本。

### 1. 准备数据文件
在运行脚本前，请确保原始数据文件 `ResaleflatpricesbasedonregistrationdatefromJan2017onwards.csv` 与 `main.py` 存放在约定的目录下（如项目根目录或 `data/` 文件夹中，具体取决于路径配置）。

### 2. 运行步骤
### **Windows 系统：**
1. **进入目录**：打开文件夹，进入存放上述文件的位置。
2. **快捷开启终端**：点击文件夹顶部地址栏（显示路径的长条区域），清空文字后输入 `cmd` 并按 **回车键 (Enter)**。
3. **启动指令**：在弹出的黑色窗口中，输入以下命令：
   ```bash
   python main.py
4. **访问系统**：按 **回车键 (Enter)**，稍等片刻，系统会自动在浏览器中弹出预测网页。

### **Mac 系统：**
1. **进入目录**：在访达（Finder）中找到该项目文件夹。
2. **右键开启终端**：在文件夹图标上点击右键，选择**在终端中打开**（Open in Terminal）。
3. **启动指令**：在弹出的窗口中输入以下命令：
   ```bash
   python main.py
4. **访问系统**：按 **回车键 (Enter)**，系统将自动启动并打开预测网页。

## 5. 交互界面操作指南
1. **参数调整**：网页左侧设有多个交互滑动条（如：房屋面积、楼龄、楼层等）。您可以通过鼠标左右拖动来实时设定房屋参数。
2. **实时预测**：每当参数发生变动，网页右侧的预测模块将动态更新并显示该组屋的**预计转售价格**。
3. **关闭系统**：使用完毕后，直接关闭浏览器网页，并关闭终端黑色窗口即可。

## 6. 注意事项
1. **文件完整性**：请勿更改 `xgb_production_pipeline.pkl` 的文件名或移动其位置，否则程序将因找不到模型而报错。
2. **运行环境**：程序运行期间请务必保持终端窗口开启；若关闭终端，网页的交互功能将失效。
